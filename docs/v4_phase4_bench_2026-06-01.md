## Durability sequence (verified by tests)

1. SST file `finalize_with_meta` -> `sync_all` (fsync).
2. Manifest `save_atomic` writes `.tmp`, fsyncs, rotates `MANIFEST -> .prev`, renames `.tmp -> MANIFEST`, fsyncs the parent directory.
3. WAL `truncate_up_to(seq)` only AFTER (1) and (2) succeed.

Crash between (1) and (2): SST is an orphan; `manifest::cleanup_orphan_ssts` renames it to `.orphan-<ts>` on restart. WAL replay reconstructs the MemTable. No data loss.

Crash between (2) and (3): WAL replay re-inserts the (already-flushed) records into the new MemTable. Phase 5 read-path dedup + Phase 6 compaction handle the duplication. No data loss.
