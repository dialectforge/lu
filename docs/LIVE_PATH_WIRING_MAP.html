The fracture in one paragraph. Before OP-007 privsep (commit 85c593f, 2026-07-18) Lu was one binary exposing ~40 MCP tools, each wiring a faculty onto the surface a user hit — the "good-responses" version John remembers. The split made two binaries: an admin binary (all tools) and a public/guest binary built default-features = false, which physically compiles src/mcp.rs out. The guest exposes only lu4d_ask + session tools, and lu4d_ask routes through one call: Brain::narrate(query, depth, top_k, false). Every faculty whose positive handler lived in mcp.rs (full math, the Q.3 session-memory pre-pass, explicit think/reason tools) was stranded off the live path. At split time narrate() read the router observation-only, so faculties couldn't switch on. Since then (OP-ROUTE-3a/3b/3c + today's OP-ROUTE-GUEST) reasoning, variants, critic-vetting, agentic-thinking and arithmetic have been re-wired into narrate() one at a time. Still stranded on guest: context/session memory (Q.3), full math, a running curiosity fill worker; confidence is globally degraded to Unverified on loaded v5 brains; off-ness/Cattle Dog never existed on main. Hypothesis "good = full binary, guest = crippled": CONFIRMED, dated to 85c593f.
